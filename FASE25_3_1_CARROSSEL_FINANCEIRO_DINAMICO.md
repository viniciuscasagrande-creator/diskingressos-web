# Fase 25.3.1 — Carrossel Financeiro Dinâmico

## Objetivo
Tornar as barras horizontais de opções financeiras mais rápidas, visuais e agradáveis, evitando a aparência de uma simples barra com rolagem.

## Aplicado
- Setas laterais inteligentes: aparecem ativas somente quando há conteúdo para navegar.
- Deslocamento suave por blocos de opções.
- Scroll do mouse convertido em navegação horizontal quando o cursor está no carrossel.
- Scroll snap para os itens assentarem naturalmente.
- Item ativo centralizado automaticamente.
- Gradientes laterais sinalizando que existem mais opções.
- Hover com elevação e destaque.
- Indicador luminoso na opção ativa.
- Responsividade para notebook, tablet e celular.
- Scrollbar visual removida.

## Locais atualizados
- Dashboard Financeiro.
- Central de Saldo, Extrato e Movimentações.

## Regra
Nenhuma função financeira ou rota foi alterada. A mudança é de experiência de navegação.
